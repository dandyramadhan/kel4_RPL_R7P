# 📚 ReadTrack

Aplikasi berbasis web untuk mencatat koleksi buku, memantau progres halaman yang dibaca, dan melacak riwayat aktivitas membaca secara terstruktur. Proyek ini dikembangkan untuk memenuhi tugas mata kuliah **Rekayasa Perangkat Lunak (RPL)** pada Program Studi Teknik Informatika, **Universitas Indraprasta PGRI**.

## ✨ Fitur Utama

* **Manajemen Data Buku:** Menambahkan buku baru, memperbarui informasi buku, menghapus data, serta melihat daftar koleksi bacaan.
* **Pelacakan Progres Membaca:** Memperbarui jumlah halaman yang telah dibaca dengan kalkulasi persentase progres secara otomatis.
* **Riwayat Membaca:** Menyimpan catatan histori aktivitas dan status penyelesaian bacaan pengguna.
* **Sistem Level Pembaca:** Fitur gamifikasi berupa 10 tingkatan level pembaca berdasarkan akumulasi total halaman yang berhasil diselesaikan.
